# Archive — phase working notes

These documents are the original working notes written while each phase of
the platform was built. They are preserved here unchanged as a record of
the build process. For the current, consolidated public documentation, see
the top-level files in `docs/` (e.g. `docs/ARCHITECTURE.md`,
`docs/DEPENDENCY_MODEL.md`, `docs/AI_GROUNDING.md`).

| File | Covers |
|---|---|
| `architecture.md` | Phase 1 dependency engine architecture |
| `phase1-results.md` | Phase 1 verification results (33-test era) |
| `dependency-model.md` | Phase 1 component/dependency model |
| `phase2-architecture.md` | Phase 2A release-intelligence architecture |
| `test-recommendation-model.md` | Phase 2A test recommendation model |
| `risk-signal-model.md` | Phase 2A risk-signal + release-checklist model |
| `ai-grounding.md` | Phase 2A AI grounding contract and hallucination guard |
| `phase2b-architecture.md` | Phase 2B incident-intelligence architecture |
| `incident-model.md` | Phase 2B incident dataset model |
| `incident-relevance.md` | Phase 2B deterministic incident relevance engine |

Counts quoted in these notes (e.g. "33 tests") reflect the phase in which
they were written. The current verified baseline is recorded in
`INTERVIEW_READY_BASELINE.md` at the repository root.
